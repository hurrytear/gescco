“GPT 20x 变 10x”说的是 **ChatGPT Pro 每月 $200 档位**相对 Plus 的 ChatGPT Work 与 Codex 用量倍率，不是某个 GPT 模型的上下文窗口、API 速率限制或所有用户的统一消息条数。以下资料核对于 2026-10-21，订阅条款与账号实际额度仍需以当前后台为准。

## 01 / 公布了什么

2026 年 9 月 29 日，OpenAI 的 Thibault Sottiaux 在[第一则 X 帖文](https://x.com/thsottiaux/status/2104823812042940713)中说明：重新开放 Pro $200 新订阅时会改变用量计算，按 API 美元价值折算，新方案约为旧版的一半；Pro 档位不重新引入五小时限制。他随后在[补充说明](https://x.com/thsottiaux/status/2104951965184925941)中给出新的相对倍率：Plus 为 1x、Pro $100 为 5x、Pro $200 为 10x。旧 Pro $200 订阅者暂时保留 20x，并获额外额度；该公开帖文没有注明到期日。一份[公开的订阅邮件截图](https://x.com/aipulseda1ly/status/2105043878373925312)则写明受影响老用户保留旧额度至 10 月 29 日，10 月 30 日起调整；具体资格与积分以本人收到的通知为准。

截至本文核对时，[OpenAI Docs 定价说明](https://learn.chatgpt.com/docs/pricing)列出了 $100、$200 和 $500 三档 Pro，说明 ChatGPT Work 与 Codex 共用订阅用量，Pro 当前没有五小时限制，但没有在公开表格中列出每档的固定 10x / 20x 数字。API Key 按 API 价格计费，不能把 Pro 的订阅倍率当成 API 余额，也不要把 Chat 中某个模型的消息上限混为同一指标。

## 02 / 10x 不等于每项工作立刻减少一半

倍率的分母是 Plus 当时的可用量。如果 Plus 的基准同时变化，`旧 20 × 旧 Plus 基准` 与 `新 10 × 新 Plus 基准` 不一定正好相差一半。Sottiaux 说会提高基础用量，但没有在帖文里给出足以替每位用户计算新绝对值的数据。另一方面，他确实把新 Pro $200 的 API 美元等值称为旧版的一半；这与“所有任务都只能做一半”不是同一结论。

模型、推理强度、上下文长度和任务方式也会影响消耗。同样一周的工作，换用成本较低的模型可能做更多任务；继续使用高消耗模型则未必能抵消额度变化。评估时应固定模型和任务样本，比对工作完成数、消耗比例、重置时间以及实际额外购买的额度，不能只看套餐标签。

## 03 / X 上几种值得看的反应

- [Theo](https://x.com/theo/status/2104825448597479886)认可明确说出 API 等值变化，但认为同价档位的减少仍然让重度用户难以接受。这是对价格与预期的判断，不是所有账号额度已同步下降的证据。
- [Corey Quinn](https://x.com/quinnypig/status/2104828602902856017)用“像 AWS 定价页”调侃公告的复杂度：如果消费者必须自己换算倍率、基准与积分，产品信息就不够容易核对。
- [Kun Chen](https://x.com/kunchenguid/status/2104830224785605105)承认 OpenAI 模型的效率优势，同时指出订阅价值调整可能给竞争对手重新定价的空间。这是市场推测，不是已发生的竞争结果。
- [Gia](https://x.com/giadotai/status/2104834232283766784)关注老 20x 订阅者会怎样，以及此前暂停新订阅与本次调整的关系；过渡权益应优先看自己收到的订阅通知和用量面板。

这些帖子代表个人观点。X 原帖在部分未登录环境可能无法展开；以上仅转述可核对的公开帖文，不把评论当成官方条款。

## 04 / 订阅者如何核对影响

打开 ChatGPT 的套餐与 Usage 页面，先确认当前是 Plus、Pro $100 还是 Pro $200，再分别查看 Work / Codex 的剩余额度、重置时间及附赠积分有效期。老订阅者还应保存通知邮件中的切换日期，对比切换前后**同一模型、同类任务**的消耗。如果页面显示与通知不一致，保留去除个人信息的时间记录，向官方支持反馈；不要通过购买多个账号绕过限制。
